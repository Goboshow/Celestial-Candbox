# Celestial-Candbox
A toy where you can play around with gravity, momentum and different bits and bobs!

Disclaimer:
this is just a fun simulation! It is not intended to be entirely accurate!

Dependencies:
Must have Tkinter, Pillow, Pygame, OS and Math.
Most of which are included with a standard installation of python, however those which are not can be installed with

pip install pygame pillow

Do not alter the files in any way, whether it be positioning or renaming, else it will crumble like my mental state while writing this.
